# Archived development reports

These HTML reports contain numeric measurements from November 4, 2026, with no camera frames or transcript text. Results are workload-specific and describe the app at that point in development.

- `latency-audit.html`: initial pipeline profile.
- `latency-current.html`: intermediate profile before the second optimization pass.
- `latency-after-round2.html`: later live-session timing breakdown.
- `decoder-preview-results.html`: an early-preview experiment. **Early preview was subsequently removed**; its provisional output is not a current feature.

Use the app's timing panel for current measurements. See [MODEL.md](../MODEL.md) for methodology and limitations.
