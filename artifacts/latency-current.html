Waiting outside those processing timers

  • First caption: a 2-second initial collection window; fresh local replays produced the first caption after 2.9–3.5 seconds.

Next targets, keeping the same prediction settings
  • Prepare incoming frames earlier. Move JPEG decoding and face tracking off the update’s critical path. Savings depend on available compute time; not yet benchmarked end to end.
  • Parallelize independent CPU image warps. A local 32-frame probe fell from 64.5 to 23.8 ms using four workers, with identical output pixels. That suggests about 40 ms to recover on comparable work; full-pipeline validation is still needed.
  • Profile decoder execution next. Sequential word generation is the main model cost. Smaller beams or weaker verification would violate the current accuracy constraint.
